# Eduardo Sánchez Mulero

I build tools that read and write undocumented binary formats, and I write the specification beside each one so that every claim can be reproduced with a command.

## Projects

**[pokopia-tools](https://github.com/eduardosmulero-tech/pokopia-tools)** — Python reader, writer and declarative mod format for a Switch 2 game's data container: 12,298 / 12,298 payloads rebuilt byte for byte, plus `G1T` texture and `G2A` animation readers. GPL-3.0.

**[eden-trace](https://github.com/eduardosmulero-tech/eden-trace)** — Instrumentation method and field notes for Switch 2 emulation on Eden-derived forks, with every finding tagged `[VERIFIED]`, `[CODE]`, `[INFERENCE]` or `[UNKNOWN]`.

**[pokopia-data-formats](https://github.com/eduardosmulero-tech/pokopia-data-formats)** — The written specification behind those tools: field tables, invariants and test vectors for the container format. No game data, no keys. CC BY-SA 4.0.

## Stack
